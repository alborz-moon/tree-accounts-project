# حساب های اصلی - پنل حامی کت

پروژه Next.js با MUI برای نمایش درخت حساب های حسابداری با قابلیت های زیر:

## ویژگی ها

- نمایش سلسله مراتبی حساب ها با قابلیت باز و بسته شدن (Expand/Collapse)
- راست‌کلیک روی هر نود برای منوی زمینه شامل:
  - **برش دادن (Cut)**: فقط برای نودهای بدون فرزند
  - **کپی کردن (Copy)**: کپی نود به همراه تمام فرزندان
  - **پیست کردن (Paste)**: چسباندن به عنوان زیرشاخه نود انتخاب شده
  - **حذف (Delete)**: فقط برای نودهای بدون فرزند
  - **افزودن زیرشاخه (Add)**: باز شدن مدال برای وارد کردن لیبل و افزودن فرزند جدید

## اجرا

```bash
cd tree-app
npm install
npm run dev
```

سپس به آدرس http://localhost:3000 بروید.

## تکنولوژی

- Next.js 14 (App Router)
- React 18
- Material UI (MUI) 5
- TypeScript
- پشتیبانی RTL برای فارسی
